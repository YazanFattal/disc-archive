# Disc Archive

A dark, early-2000s-inspired archive of 100 original PlayStation games and 100 PlayStation 2 games. Browse by console, search or filter the collection, and open any cover for a short game profile.

The site uses plain HTML, CSS, and JavaScript. Open `index.html` locally or serve this directory from a static web server.

For GitHub Pages, use **Settings → Pages → Deploy from a branch → main → / (root)**.

Cover scans are sourced from [Libretro](https://github.com/libretro-thumbnails). Cover art belongs to its respective rights holders. Font licenses are in the `fonts` directory.
