# Disc Archive

A dark, early-2000s-inspired archive of 300 games across the original PlayStation, PlayStation 2, and Xbox 360. Browse by console, search or filter the collection, and open any cover for a short game profile.

The site uses plain HTML, CSS, and JavaScript. Open `index.html` locally or serve this directory from a static web server.

For GitHub Pages, use **Settings → Pages → Deploy from a branch → main → / (root)**.

PlayStation cover scans come from [Libretro](https://github.com/libretro-thumbnails). Xbox 360 cover scans come from the [LaunchBox Games Database](https://gamesdb.launchbox-app.com/). Cover art belongs to its respective rights holders. Font licenses are in the `fonts` directory.
